DF Code Garena
===============

Tiện ích chỉ nhập code khi tab Trung Tâm Đổi Quà đang mở:
https://redeem.df.garena.sg/vi/cdkgarena.html

Cài trên máy tính (Chrome hoặc Edge)
1. Xóa thư mục bản cũ nếu đã giải nén trước đó. Không giải nén đè.
2. Giải nén file zip. Chọn cả thư mục df-code-garena, không chọn từng file bên trong.
3. Mở chrome://extensions hoặc edge://extensions.
4. Bật Chế độ dành cho nhà phát triển.
5. Bấm Tải tiện ích đã giải nén (Load unpacked) và chọn thư mục df-code-garena.
6. Đối chiếu SHA256SUMS trong thư mục vừa giải nén. Cách kiểm tra nằm cuối file đó. Chỉ tải từ https://github.com/toilabaothien19-web/redeem.df.garena

Dùng
1. Mở trang đổi code và đăng nhập Garena. Tiện ích không hỏi mật khẩu.
2. Bấm biểu tượng DF. Nếu trang mở từ trước khi cài, bấm F5 rồi mở lại tiện ích.
3. Dán code hoặc bấm Mở file .txt. Mỗi dòng một code. Dòng bắt đầu bằng # được bỏ qua. Nút Xóa toàn bộ chỉ xóa danh sách trong ô, không xóa log. Demo Code là danh sách mẫu, có thể đã hết hạn. Mỗi code sai là một lần thử trên tài khoản của bạn.
4. Nên để bật Bảo vệ tài khoản. Khi bật: nghỉ ngẫu nhiên 20–30 giây, tối đa 30 code mỗi lần bấm, 30 code mỗi 60 phút và 60 code mỗi 24 giờ. Tắt bảo vệ thì tối đa 100 code mỗi lần và có hỏi lại. Không thể cam kết tài khoản không bị khóa.
5. Bấm Bắt đầu. Có thể đóng popup, việc nhập vẫn chạy tới khi hết danh sách hoặc bấm Dừng. Không mở hai tab đổi quà để chạy cùng lúc.
6. Code lỗi được ghi nguyên câu hiện trên trang và nguyên câu máy chủ gửi, kèm mã số. Bấm Chép mã lỗi để copy đúng dòng đó. Kết quả chưa xác định không bị tính là lỗi và không bị bỏ qua lần sau.
7. Bấm Xuất log để tải file .txt. Phần DÙNG ĐƯỢC là code thành công. Phần LỖI ghi đúng câu lỗi. Đọc file log trước khi chia sẻ.
8. Bấm Tải log lên để nạp lại file đó. Lần chạy sau bỏ qua code đã thành công và code lỗi, không bỏ qua dòng chưa xác định.

Bảo mật
- Mã tiện ích được viết riêng cho việc này. Không nhúng thư viện hay mã nguồn bên ngoài.
- Mã nguồn không có lệnh gửi dữ liệu đi nơi khác. CSP chặn kết nối ở popup và service worker. Phần chạy trên trang Garena không chịu CSP đó, nhưng cũng không có lệnh tự gửi mạng.
- Không đọc và không lưu cookie, tên đăng nhập, mã đăng nhập.
- Không đọc phản hồi đăng nhập. Chỉ nhìn phản hồi của đúng lần đổi code đang chạy.
- Lệnh nhập code đi qua một kênh riêng. Script trên trang không giữ kênh đó, nên không ra lệnh nhập và không sửa kết quả.
- Câu lỗi được giữ nguyên văn, nhưng token, email, liên kết và dãy số dài bị xóa trước khi ghi nhật ký.
- Không có trình theo dõi. Log chỉ nằm trên máy bạn, trừ khi chính bạn tải file đi.

Nếu trạng thái báo phải tải lại trang, bấm F5 trên trang đổi code rồi mở lại tiện ích.
Không dùng được trên Chrome điện thoại.
Cần Chrome hoặc Edge từ phiên bản 111 trở lên.
Nếu đã cài bản cũ, xóa thư mục cũ, giải nén bản mới, rồi bấm tải lại trên trang tiện ích.
