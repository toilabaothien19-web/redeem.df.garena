DF Code Garena
===============

Tiện ích chỉ nhập code khi tab Trung Tâm Đổi Quà đang mở:
https://redeem.df.garena.sg/vi/cdkgarena.html

Cài trên máy tính (Chrome hoặc Edge)
1. Giải nén file zip. Chọn cả thư mục df-code-garena, không chọn từng file bên trong.
2. Mở chrome://extensions hoặc edge://extensions.
3. Bật Chế độ dành cho nhà phát triển.
4. Bấm Tải tiện ích đã giải nén (Load unpacked) và chọn thư mục df-code-garena.

Dùng
1. Mở trang đổi code và đăng nhập Garena. Tiện ích không hỏi mật khẩu.
2. Bấm biểu tượng DF.
3. Dán code, bấm Mở file .txt, hoặc bấm Demo Code nếu chưa có code. Mỗi dòng một code. Dòng bắt đầu bằng # bị bỏ qua. Nút Xóa toàn bộ chỉ xóa danh sách trong ô, không xóa log.
4. Nên để bật Bảo vệ tài khoản. Khi bật, thanh kéo và nghỉ ngẫu nhiên được ẩn, mỗi code sau nghỉ ngẫu nhiên 20–30 giây, dừng sau 30 code hoặc 5 lỗi liên tiếp. Không thể cam kết tài khoản không bị khóa.
5. Bấm Bắt đầu. Có thể đóng popup, việc nhập vẫn chạy tới khi hết danh sách hoặc bấm Dừng.
6. Code lỗi được ghi nguyên câu hiện trên trang và nguyên câu máy chủ gửi, kèm mã số. Bấm Chép mã lỗi để copy đúng code và câu đó.
7. Bấm Xuất log để tải file .txt. Phần DÙNG ĐƯỢC là code thành công. Phần LỖI ghi đúng câu lỗi.
8. Bấm Tải log lên để nạp lại file đó. Lần chạy sau tự bỏ qua code đã nhập và code lỗi.

Bảo mật
- Mã tiện ích được viết riêng cho việc này. Không nhúng thư viện hay mã nguồn bên ngoài.
- Không tự gửi dữ liệu đi đâu. Không đọc và không lưu cookie, tên đăng nhập, mã đăng nhập.
- Không đọc phản hồi đăng nhập. Chỉ nhìn phản hồi của đúng lần đổi code đang chạy.
- Không nhận lệnh từ trang web. Chỉ popup của tiện ích mới bấm được Bắt đầu.
- Câu lỗi được giữ nguyên văn, nhưng token, email và liên kết bị xóa trước khi ghi nhật ký.
- Không có trình theo dõi. Log chỉ nằm trên máy bạn, trừ khi chính bạn tải file đi.

Nếu trạng thái bảo tải lại trang, bấm F5 trên trang đổi code rồi mở lại tiện ích.
Không dùng được trên Chrome điện thoại.
Nếu đã cài bản cũ, vào trang tiện ích và bấm nút tải lại (reload) sau khi giải nén bản mới đè lên thư mục cũ.
